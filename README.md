# 🎮 Guess the Number Game (with Voice Assistant)

A fun and interactive **number guessing game** in Python, enhanced with **text-to-speech** using `pyttsx3`. The computer picks a random number between 1 and 100, and you try to guess it within a set number of attempts — with real-time voice feedback!

---

## 🔊 Key Features

- 🎲 Random number between 1 and 100
- 🗣️ Voice assistant via `pyttsx3` for instructions and feedback
- 🎯 Customizable number of attempts
- 🚪 Option to start or exit the game
- 🎮 Guided user input with helpful hints

---

## 🎥 Sample Interaction

```text
Gamer: How many chances do you want?
> 5

Gamer: Insert 1 to start the game and 2 to exit.
> 1

Gamer: Let's start the game!
Attempt 1 - Enter your guess: 40  
Gamer: You chose a smaller number. Try a higher one.  
...
Gamer: Good job! You guessed the correct number.
